# Учебный стенд анализа процесса абсорбции

Настольное приложение для студентов АТПП, которое показывает причинно-следственную связь:

```text
возмущение → объект управления → изменение выхода → реакция регулятора
```

Программа использует упрощённые материальные балансы и динамическую модель первого порядка. Она предназначена для учебных демонстраций, а не для проектного расчёта промышленного абсорбера.

## Возможности

- две цепи расчёта: концентрация обеднённого газа и концентрация насыщенного абсорбента;
- положительные и отрицательные возмущения состава и расхода в диапазоне от `−0,99` до `9,99`;
- ступенчатое, импульсное, временное прямоугольное и плавно нарастающее воздействие;
- настройка момента и длительности воздействия, времени моделирования, постоянной времени `T` и запаздывания `L`;
- сравнение исходного режима, отдельных возмущений состава и расхода и их совместного действия;
- сравнение свободной реакции объекта с P-, PI-, PD- и PID-регулированием;
- автоматический подбор параметров регулятора;
- графики выхода, ошибки регулирования и управляющего воздействия;
- структурная схема, ход расчёта и показатели переходного процесса;
- готовые лабораторные сценарии и режим предварительного прогноза результата;
- экспорт двух графиков в PNG, точек в CSV и протокола расчёта в TXT или буфер обмена.

## Модель

Динамика объекта описывается апериодическим звеном первого порядка:

```text
T · dy/dt + y = yуст
```

Для совместного относительного изменения состава `k₁` и расхода `k₂` используется произведение факторов:

```text
kсовм = (1 + k₁) · (1 + k₂) − 1
```

Модель позволяет отдельно задавать чистое запаздывание и исследовать влияние настроек регулятора на переходный процесс.

## Требования

- Python 3.14;
- Tkinter/ttk;
- NumPy;
- Matplotlib с поддержкой Tk.

В официальной сборке Python для Windows Tkinter обычно уже включён.

## Установка и запуск

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install numpy matplotlib
python main.py
```

Если необходимые библиотеки уже установлены в выбранном интерпретаторе, достаточно выполнить:

```powershell
python main.py
```

## Проверка

Полный набор модульных тестов запускается командой:

```powershell
python -m unittest discover -s tests -v
```

## Структура проекта

```text
main.py                 интерфейс Tkinter/ttk
calculations.py         динамическая модель и регуляторы
simulation.py           подготовка и выполнение расчёта
model_dialog.py         окно параметров математической модели
laboratory.py           сценарии и проверка прогноза студента
exporting.py            экспорт графиков, таблиц и протокола
validation.py           проверка введённых значений
tests/                  модульные тесты
```

## Ветки

- `stable` — стабильная версия и ветка по умолчанию;
- `trunk` — актуальная ветка разработки;
- `legacy` — предыдущая версия интерфейса на PySimpleGUI.
